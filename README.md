All free software under the AGPL-3.0, with signed releases where there are releases.

### How we build it

- **Rebel.** We build the open alternative, and we don't ask permission to start.
- **Rigorous.** Every change goes through a pull request, with tests in CI and a readable changelog.
- **Secure.** A private way to report vulnerabilities, signed releases, and reported issues fixed first.
- **Free.** Copyleft by default, so what we open stays open. Contributors keep their copyright: no CLA, just `git commit -s`.
